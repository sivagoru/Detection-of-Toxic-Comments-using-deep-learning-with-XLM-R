# Detection-of-Toxic-Comments-using-deep-learning-with-XLM-R
Toxic Comment Detection using Deep Learning with XLM-R

A multilingual Toxic Comment Detection system developed using Deep Learning and the XLM-RoBERTa (XLM-R) transformer model to identify toxic, abusive, offensive, and harmful comments from online platforms and social media.

This project focuses on Natural Language Processing (NLP) and Deep Learning techniques for understanding contextual meaning in multilingual text data. The system is capable of detecting toxic language more effectively compared to traditional machine learning approaches.

🚀 Project Overview

Online platforms and social media often contain harmful comments, abusive language, hate speech, and toxic content that negatively affect users and communities. Traditional machine learning models struggle to understand contextual meanings, sarcasm, and multilingual text.

To overcome these limitations, this project uses the XLM-R transformer model, a powerful multilingual language model capable of understanding contextual relationships between words in different languages.

The model is trained using the Jigsaw Toxic Comment Classification dataset and can classify comments into toxic and non-toxic categories.
